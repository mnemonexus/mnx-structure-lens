How each feature was checked
----------------------------
1. Every file is the unmodified mmCIF from files.rcsb.org (entry data CC0). dev/structure-lib.mjs reads auth_asym_id, auth_seq_id,
   auth_comp_id and auth_atom_id of the first model: the same ids 3Dmol's CIF reader gives the viewer.
2. dev/verify-structures.mjs checks, for every selector of every target: the chain exists, the residue number exists, the residue name
   matches (single residues and ligands), run sequences match the one-letter text in the JSON, named atoms exist; plus term rules,
   cite ids (each packet:line must be a key of that packet's lines.json or figures.json) and that no ask/hint repeats a residue number.
   Result: "no errors" for 31 activities, 84 targets, 29 structures.
3. Independent numbering checks against UniProt (the kind of source a reader can open): sequence of each protein chain compared with
   the UniProt sequence at a fixed offset (matches counted), and the UniProt 'Active site / Binding site / Metal binding' features
   mapped onto the file's residues. Offsets: UniProt = file + 0 (chymotrypsin P00766, ketosteroid isomerase P00947, Rho P0AG30,
   RNAP beta prime P0A8T7, RNAP beta P0A8V2, sigma70 P00579, P450 3A4 P08684, DnaA P03004, photolyase P05327, MGMT P16455);
   + 1 (liver ADH P00327, aspartate aminotransferase P00503); + 9 (UDG P13051); + 18 (lysozyme P00698); + 21 (acetylcholinesterase
   P04058); + 25 (MCAD P41367); + 26 (Cel6A Q9C1S9); + 110 (carboxypeptidase A P00730); + 232 (thermolysin P00800).
4. Geometry from the coordinates (distances in angstroms) where a role could be tested.
